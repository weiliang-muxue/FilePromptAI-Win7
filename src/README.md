# FilePrompt AI for Windows 7

FilePrompt AI 是一个面向 Windows 7 和内网自定义模型的文件问答客户端，不依赖
WebView2。当前维护版本为 **v1.18**。

## 能做什么

- 连接 OpenAI Chat Completions 兼容的内网模型，可配置完整请求 URL、模型名称和
  可选 API Key。
- 读取用户主动添加的文本、代码、PDF、DOC/DOCX、RTF、XLS/XLSX、PPTX 和 XMind，
  也可发送 PNG、JPEG、BMP、GIF、TIFF 图片。
- 支持拖放、文件选择、剪贴板内容和手工粘贴文件路径；不会扫描目录。
- 支持多会话、搜索、置顶、归档、分支、备份和恢复。
- 支持流式回复、停止生成、重新生成和失败后重试，并按 Markdown 标题、列表、代码块
  和表格排版。
- 可把回答或整个会话导出为 Markdown、文本、Word、PDF、PowerPoint 和 XMind；
  Markdown 表格还可导出为 Excel 或 CSV。
- 支持完全离线保存的技能，以及需要用户明确启用的本地 stdio 和 Streamable HTTP MCP。
- 程序配置和会话保存在本机，安装和启动过程不访问互联网。

## 下载和安装

1. 下载 **FilePromptAI-Win7-Full-v1.18.zip**。
2. 将 ZIP **完整解压**到一个文件夹。不要在压缩包内直接运行，也不要只复制其中某个
   EXE 或只复制 `app` 目录。
3. 进入解压目录，双击 **Start-FilePromptAI.exe**。如果电脑缺少 .NET Framework 4.8，
   启动器会先校验并运行包内的微软官方离线安装程序，不会联网下载；如果安装程序要求
   重启，重启电脑后再次双击启动器。

普通用户只需使用 `Start-FilePromptAI.exe`。无需运行 `Verify-FilePromptAI.exe`，
也无需使用 `--archive` 参数。

## 首次配置

1. 打开左侧“设置”→“模型连接”。
2. 填写模型服务的**完整请求 URL**，例如单位提供的 Chat Completions 地址。程序不会
   自动补全路径或把请求改成其他协议。
3. 填写模型名称。标准 OpenAI 兼容服务也可通过“获取模型”读取同源 `/models` 列表。
4. 按服务要求填写 API Key；Ollama、vLLM 等无需鉴权的服务可留空。
5. 使用“测试连接”确认配置，然后选择“保存并关闭”。

设置窗口中的修改只有在保存并关闭后才写入本地配置。可在“模型配置...”中保存多个
内网模型预设，之后从主窗口快速切换。

程序固定使用 Chat Completions 请求格式。服务端需要接受 `POST`、`messages`、
`model` 和可选的流式响应；程序也兼容常见网关返回的 Responses 文本事件封装、
`delta.text` 和 NDJSON 文本分片。

## 日常使用

### 问答

在底部输入问题，按 Enter 或点击发送。生成过程中可以停止；失败后可以从失败位置重试，
也可以对最新模型回复原位重新生成。超长会话会按完整问答轮次保留最近上下文，不会拆开
单条消息。

“快捷指令”可以保存常用的总结、翻译、PPT 大纲、XMind 结构或表格提示词。模板只会
载入编辑器，不会自动发送。

### 添加附件

- 将文件拖到专用拖放区，或通过“+ 添加”选择文件、粘贴内容或打开路径窗口。
- 粘贴路径后，只有主动点击“添加”才会读取；程序不会因为剪贴板里出现路径就后台访问。
- 双击附件或按 Enter 可以预览已经读取的文字和图片。
- 模型只会收到文件名、提取出的内容和内联数据，不会收到本地文件路径。
- 文本内容可以进入会话历史；图片和其他无文本二进制附件只在当前轮发送，后续需要时
  必须重新添加。
- 当前运行期间，所有会话的未发送二进制附件合计上限为 20 MB；单次请求在 Base64
  编码前后也会检查 32 MB 上限。

### 管理会话

左侧会话列表支持新建、重命名、搜索、置顶、归档、移回和删除。可以从最新模型回复
创建独立分支，分支复制此前上下文，原会话保持不变。

会话可备份为 `.fpc` 文件并合并恢复。备份包含会话内容，但不包含请求 URL、API Key
或模型配置。切换会话时，本次运行期间尚未发送的草稿会保留。

### 导出结果

可从最新回复或整个会话导出 Markdown、文本、Word（`.docx`）、PDF、
PowerPoint（`.pptx`）和 XMind（`.xmind`）。回答中的 Markdown 表格还可导出为
Excel（`.xlsx`）或 CSV。导出在本机完成，不要求安装 Microsoft Office 或 XMind。

中文 PDF 导出需要系统具有可嵌入的中文字体，例如 Microsoft YaHei、SimSun 或
Noto Sans SC。

### 可选的技能与 MCP

离线技能是保存在本机的模型指令，可手工创建，或从剪贴板、用户明确选择的单个
`SKILL.md`、JSON 或文本文件导入。程序不会扫描目录、执行导入文件中的脚本，或因为
导入而联网。

MCP 支持本地 stdio 和 Streamable HTTP。导入的 MCP 默认停用；stdio 服务首次启动及
每次工具调用默认都需要确认。本地 MCP 所需的 Node.js、Python、Java 或其他运行环境
不随客户端安装，必须由管理员另行离线准备。只启用来源可信、已经审查的 MCP。

## 验证下载

### 普通用户可选：核对 ZIP 的 SHA-256

从可信的 v1.18 发布页或带注释的 `v1.18` Git 标签取得
`src/RELEASE-SHA256.txt` 中公布的摘要，然后在 ZIP 所在目录运行：

```powershell
(Get-FileHash .\FilePromptAI-Win7-Full-v1.18.zip -Algorithm SHA256).Hash
```

计算结果应与可信来源公布的摘要完全一致。此步骤是可选的文件身份核对，不影响正常
启动；不要使用 ZIP 内部的文件替代可信来源提供的摘要。

### 发布维护者可选：Windows 7 验收

`Verify-FilePromptAI.exe` 是发布取证工具，不是应用启动器。`--archive` 只用于
发布维护者把原始 ZIP 与 Windows 7 验收报告绑定。普通用户无需运行验收器，也不要把
`--archive` 传给启动器。

正式验收的环境、命令、报告和发布证据链见
[开发、测试与发布维护说明](DEVELOPMENT.md)。

## 系统要求

- Windows 7 必须安装 Service Pack 1；也支持 Windows 8、Windows 10 和 Windows 11。
- 程序需要 .NET Framework 4.8。完整包已经附带微软官方完整离线安装程序，缺少时由
  启动器提示并自动调用，无需用户另行下载。
- 解压后的客户端运行不依赖 PowerShell，也不需要另装 WebView2、VC++ 运行库、
  Node.js、Python、Java 或 Microsoft Office。
- 长期未更新或经过精简的 Windows 7 可能需要管理员先离线安装微软 SHA-2 代码签名
  支持、最新服务堆栈，以及提供 `D3DCompiler_47.dll` 的系统更新；这些 Windows
  补丁不在应用包内。
- 访问 HTTPS 模型或 HTTP MCP 地址时，Windows 需要支持 TLS 1.2，并信任服务端证书；
  单位内部 CA 的根证书需由管理员预先导入系统证书库。

1920×1080、100% 缩放只属于正式发布验收环境要求，不是普通用户运行程序的前置条件。

## 卸载

运行完整解压目录根部的 `Uninstall-FilePromptAI.exe`，或依次选择左侧
“设置”→“维护”→“卸载程序...”。

卸载器会先校验发布清单和相关文件。文件缺失、被修改、被占用或路径身份异常时会在
删除前停止。发布目录中的额外文件不会被递归删除。用户配置和会话默认保留；只有明确
勾选并再次确认后才删除。

如果提示缺少 `PACKAGE-CHECKSUMS-SHA256.txt`，请重新完整解压原 ZIP，不要只复制
卸载器。正常数据目录固定为 `%LocalAppData%\FilePromptAI-Win7`。

## 安全与联网边界

- 安装和启动不访问互联网，也不会在线下载依赖、更新、遥测或扩展。
- 生成内容时只连接用户填写的完整模型请求 URL；模型请求和主动模型列表请求不使用
  Windows 系统代理，也不跟随 3xx 重定向。
- API Key、MCP 命令、环境变量、URL 和请求头使用当前 Windows 用户的 DPAPI 加密保存。
- 程序只读取用户当次明确选择、拖入、粘贴或确认添加的文件，不扫描目录；本地路径不会
  发给模型。
- 会话文件无法安全读取时，程序进入只读保护，不覆盖原文件；确认内容损坏时会先在同一
  目录重命名保留。
- 关闭程序时如有未发送文字、附件或运行中任务，会先要求确认。
- stdio MCP 是独立本地进程，其文件和系统访问能力取决于自身实现及当前用户权限；
  FilePrompt AI 的配置脱敏不能约束恶意 MCP，启用前必须确认来源和行为。
- 基础问答只需要用户配置的 OpenAI Chat Completions 兼容端点。模型服务不可达时无法
  生成内容，这与安装依赖无关。
